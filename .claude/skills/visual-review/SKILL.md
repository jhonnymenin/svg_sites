# Visual Review

Do not review only the source code.

Inspect the rendered interface.

Use browser tooling or Playwright when available.

Review desktop and mobile.

## Evaluate

### Composition
- Is there a strong focal point?
- Does the page have rhythm?
- Do sections feel deliberately composed?
- Is there unnecessary repetition?

### Typography
- Is hierarchy immediately clear?
- Is typography doing enough visual work?
- Are line lengths and spacing appropriate?
- Does it feel generic?

### Imagery
- Are crops intentional?
- Are images large enough to have impact?
- Do imagery and typography work together?
- Are there weak placeholders or inconsistent treatments?

### Spacing
- Are sections too compressed or too empty?
- Is whitespace creating hierarchy?
- Is vertical rhythm consistent?

### Brand character
- Could this exact page belong to another random company?
- Is there a recognizable visual personality?
- Are there memorable moments?

### Motion
- Is motion meaningful?
- Is anything distracting?
- Does the page feel alive where appropriate?
- Are reduced-motion considerations respected?

### Mobile
- Does mobile feel designed?
- Are important sections visually strong?
- Are images cropped well?
- Is anything merely shrunk from desktop?

## Fix

Do not only report issues.

When tasked with improving the page, fix the highest-impact visual issues directly.

Prefer a few meaningful improvements over many decorative additions.

After changes, inspect again.
