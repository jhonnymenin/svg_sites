# Responsive Design

Treat each breakpoint as a deliberate composition.

Verify at minimum:
- 390px
- 768px
- 1440px

For each viewport evaluate:
- hierarchy
- reading order
- typography scale
- text measure
- image crop
- section spacing
- navigation
- touch targets
- overflow
- animation behavior
- perceived density

Do not preserve desktop layout merely for consistency.

On mobile, simplify when necessary.

Reorder, resize, crop, stack, hide, or rethink visual elements where it improves the experience.

Avoid horizontal overflow unless it is an intentional interaction.

Any intentionally horizontal interaction must remain obvious and usable on touch devices.
