# Frontend Design

Build interfaces that look intentionally designed rather than generated from common UI defaults.

Before implementation:
1. inspect CLAUDE.md
2. inspect relevant docs
3. inspect available visual references and assets
4. understand the page goal
5. identify the strongest visual idea

When a visual direction does not yet exist, use the art-direction skill first.

## Implementation principles

Prioritize:
- hierarchy
- typography
- image composition
- section rhythm
- responsive composition
- interaction quality

Do not solve every section with a container containing cards.

Use full-bleed layouts, overlapping compositions, typography-led sections, editorial grids, horizontal structures, unusual image crops, and controlled asymmetry when appropriate.

Use reusable primitives without allowing the component library to dictate the design.

## Effects

Effects should emerge from the visual concept.

Possible techniques include:
- scroll-linked transformations
- masked image reveals
- parallax
- sticky storytelling
- horizontal scrolling
- layered typography
- image scale transitions
- text reveals
- cursor-aware interactions
- cinematic section transitions

Use restraint.

## External references

When given a website reference:
1. study what makes the reference effective
2. identify reusable design principles
3. implement an original interpretation
4. do not blindly reproduce branding or proprietary visual assets

## Completion

After building:
- verify desktop
- verify mobile
- perform visual review
- improve weak sections
- run lint/build

Do not stop at the first functional implementation.
